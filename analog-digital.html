FIG.02 — ANALOG

Analog: the smooth one 〰

Changes continuously. Any value inside the range is allowed — not just two steps. Drawn as a smooth sine wave. Think natural voice, old radio.
समयसँग लगातार परिवर्तन हुन्छ। range भित्र जुनसुकै मान हुन सक्छ। smooth sine wave मा देखाइन्छ — जस्तै प्राकृतिक आवाज।
CONTINUOUSPEAK = top (+V)VALLEY = bottom (−V)AMPLITUDE = height = strength

Zero line in the middle. Above = positive voltage, below = negative. Bigger swing = louder / stronger.

PEAK / VALLEY / AMPLITUDE / TIME — all on one wave.

FIG.03 — DIGITAL

Digital: the stepped one ▓

Fixed levels only. Usually two: HIGH = 1, LOW = 0. Waveform is square steps, not smooth. That's what computers eat.
मान fixed/discrete मात्र — HIGH = 1, LOW = 0। Wave square-step हुन्छ। कम्प्युटरले यही बुझ्छ।
💡
OFF — LOW / 0 · 0V
Try it: the switch

थिच्नुहोस् — बत्ती, भोल्टेज, binary, wave सबै सँगै बदलिन्छ।

OFF = 0V = 0 · ON = 5V = 1
